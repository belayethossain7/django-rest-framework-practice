# 🧠 Django REST Framework Practice

This repository contains my hands-on practice work with **Django REST Framework (DRF)**.  
It includes examples of building RESTful APIs, using serializers, handling models, performing CRUD operations, and exploring authentication in Django.

---

## 🚀 Features

- Django REST Framework setup and configuration  
- Model-based API development  
- Serializer and ViewSet examples  
- CRUD (Create, Read, Update, Delete) operations  
- API testing with Django shell and Postman  
- Authentication and permissions  

---

## 🏗️ Tech Stack

- **Backend:** Django, Django REST Framework  
- **Database:** SQLite / PostgreSQL  
- **Language:** Python 3.x  
- **Tools:** Postman, VS Code
